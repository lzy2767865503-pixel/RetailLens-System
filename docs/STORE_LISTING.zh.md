## 产品名称

Retail Decision Studio by LAI ZEYU

## 简短描述

中英文零售商业评估工具，提供可复算的确定性评分与由使用者控制的可选 AI 解读。

## 详细描述

Retail Decision Studio by LAI ZEYU 把结构化零售商业资料转化为可重复计算的中英文管理决策底稿。本 Windows 应用基于所链接源代码仓库中的 RetailLens 开源项目构建。

设计与作者：**LAI ZEYU（来泽宇）**。

九步填写流程覆盖顾客、零售业态、国家与城市、渠道、选址、合规、供应链、单位经济、组织、风险和证据。Retail Decision Studio by LAI ZEYU 随后使用版本化 100 分规则及不可被其他高分抵消的硬门槛，生成：

- 相同输入始终一致的确定性评分；
- 优势、缺口、证据质量、置信度和优先行动；
- 五力、竞争态势、STP 与定位、进入模式、生产力、服务缺口、组织控制及风险分析；
- EFE、IFE、IE 与 QSPM 战略视图；
- 面向管理层的 30/60/90 天决策底稿。

核心评估安装后可离线使用，不需要账户或 API 密钥。可选 OpenAI 解读使用使用者自己的 API 密钥，且只会在使用者主动请求后执行。AI 只读取锁定结果，不能修改评分。OpenAI 属于独立第三方服务：本产品不附带 OpenAI API 密钥、API 额度或 ChatGPT 订阅；使用者通过自己的 OpenAI 账户调用 API 时，可能需要另行付费。

草稿只保存在应用本机存储中。Retail Decision Studio by LAI ZEYU 不包含广告、分析追踪或开发者运营的遥测。可通过“关于与隐私”清除本机保存的商业数据。

内置演示为合成样例，不代表真实企业或当前市场情况。Retail Decision Studio by LAI ZEYU 是决策支持工具，不构成法律、税务、会计、投资或监管建议。

## 主要功能

- 中英文界面与报告
- 九步结构化零售商业评估
- 可复算的 100 分确定性评分
- 合规与风险硬门槛
- 八个企业理论分析模块
- 管理层决策底稿及 30/60/90 天路线图
- 使用者自带密钥的可选 OpenAI 解读
- 本机存储与一键数据清除
- 无账户、广告、分析追踪或遥测
